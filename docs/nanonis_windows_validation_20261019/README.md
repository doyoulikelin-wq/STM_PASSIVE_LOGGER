# Nanonis Windows 实机接口历史验证 · 2026-10-19

本目录是本轮Windows目标实例验证的发布副本，**不是自动进针工具，也不含仪器连接或硬件控制脚本**。报告与归档区分用户原Demo文档、接口协议成功、已有图缓冲、本次新采集及未验证项目。

## 主要结果

- 初轮294个不同读取命令：**164项协议成功 + 128项设备明确错误 + 2项成功状态但载荷结构不符**。打开Bias Sweep和Generic Sweep后另5项恢复成功；保留294项原始基线，不把补测覆盖为初测成功。同一294命令集合最新成功名称为169，扫描FrameDataGrab另行验证、不在该分母内。
- 读取了128个信号索引值；索引可能包含未接入/未启用通道，不等于128个有效物理传感器。两次完整频谱各512点，读取起点间隔约3.38秒且512点均变化；设备采集时间未知。
- 3通道×正反向48×48已有部分扫描缓冲：正向1200、反向1248个有限点，其余为NaN；两轮相同，不是本次新完成扫描。
- **两次进针均未确认落定**。Start ACK至Stop ACK间隔为2.285741秒和60.196918秒；首轮追加撤回在14:47:22.85独立确认。最终反馈/进针/扫描均关闭、Z约+100nm，支持仪器回读意义上的撤回，不是独立测得针尖—样品物理间距。SafeTip和软件Z限位保持原来的关闭状态，未宣称2nA硬保护。
- 7条进针/停止/撤回事务获得ACK（2启动+2停止+3撤回），另3条仅打开窗口调用单独计数。原生实验员GUI完整语义事件流未验证。
- 独立离线QA：**55项通过、0项硬性数值错误**，状态为`PASS_WITH_WORDING_CLARIFICATIONS`。QA保留审阅时原汇总哈希，报告已按其建议收紧因果措辞。浏览器筛选、导航、3图加载及窄窗布局通过。
